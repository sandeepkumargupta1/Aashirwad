# Crop photo credits

These are reference photographs of crops, not photographs or evidence from the selected farm. They are stored locally so crop identification does not depend on an external image host.

The supplied files are Wikimedia Commons thumbnails of the linked originals. Images are displayed at different sizes and may be cropped by the layout; plant features have not been retouched. Each image retains the license listed below. The source and license links are also available on the app’s Data & sources page.

## Map layers

- Streets: [OpenFreeMap](https://openfreemap.org/), [OpenMapTiles](https://openmaptiles.org/), and [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Browsers without WebGL use the [FOSSGIS raster service](https://www.fossgis.de/).
- Satellite: [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9). Service credits: Esri, Vantor, Earthstar Geographics, and the GIS User Community. Image dates and detail vary by area; this is not a live feed.
- Terrain: [OpenTopoMap](https://opentopomap.org/about), using OpenStreetMap and SRTM data; map style [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Native zoom is capped at 17; zooming closer enlarges the available map.

Basemaps provide visual location context. They do not supply measured soil conditions, crop health or groundwater observations. Visible attribution changes with the selected layer. External tile service availability and publisher terms apply.
